# Ícones das concept arts

Os arquivos desta pasta foram recortados diretamente das seis pranchas PNG
fornecidas para o iFeed. Cada elemento foi preservado como PNG transparente,
sem redesenho e sem dependência de CDN.

## Grupos

- `home-*`: selo, benefícios e indicadores da página Início.
- `journey-*-3d`: jornada colorida usada na página Início.
- `journey-*-outline`: jornada linear usada em Como funciona.
- `impact-stat-*`: quatro indicadores do topo de Impacto.
- `env-*`: cinco pilares de impacto ambiental.
- `calc-*`: cinco etapas do cálculo demonstrativo.
- `about-*`: missão, visão, valores, doadores, rede e recebedores.

As pranchas originais não são necessárias em produção e, por isso, não foram
duplicadas dentro do projeto.
